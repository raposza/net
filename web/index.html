Current is the last confirmed upgrade on the SV Operations Schedule whose date has arrived. The schedule states what the operators intend, so a date that has arrived is not proof the upgrade ran. Minimum is the oldest version a validator may run. Next is the earliest upgrade still ahead, confirmed or not. SVs on it counts the Super Validator nodes whose own roster entry reports that version. Reported is the version the network's own info document states.

Super Validators

The hosts each Super Validator node publishes, as the network's own DSO document states them. Scan is the node's public read endpoint. A participant connects to a sequencer, and the sequencer changes at every synchronizer serial: while an upgrade is in flight, and for a while after it, a node lists one per serial, highest first. A serial below the one the network reports as current is marked legacy, one above it successor.
